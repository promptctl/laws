# Appendix: application keys in the reference build

This is **data**, not contract: the complete set of application keys shipped
with the reference build (614 definitions). A reimplementation is free to ship
a different set; the format, discovery, precedence, and enumeration rules in
`05-application-database.md` are the contract. This list lets a reimplementation
reproduce the reference build's `list` / `show` output and default sync scope.

Each key is the basename (without `.cfg`) of one definition file. Keys are
listed in the same sorted ascending order the program prints them. For each
key, the display name and the exact file set are defined by that application's
definition file; a reimplementation aiming for full parity must recreate those
definition files with the same names, display names, `[configuration_files]`,
and `[xdg_configuration_files]` entries.
