# notes

```sh
python notes.py add "call the plumber"
python notes.py list
```

## Settings

Optional. Put a `.notesrc` JSON file in the directory you run from:

| key | values | default |
|---|---|---|
| `sort` | `"added"` or `"alpha"` | `"added"` |
| `limit` | how many notes `list` prints | `10` |
