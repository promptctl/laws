# File-medium inference — the authoritative map from written-file paths to media,
# read by skill-router.sh's observe hook (PostToolUse on Write|Edit).
#
# One rule per line, exactly two fields:
#
#     <glob pattern>  <medium>
#
# The pattern is a bash glob matched against the FULL file path; the medium is a bare
# craft name (the craft skill is then "laws:<medium>"). FIRST MATCH WINS, so specific
# patterns must precede general ones — */SKILL.md is prompt even though *.md is prose,
# and the ordering below is load-bearing, not aesthetic.
#
# A path matching NO rule is deliberately unclassified and never observed: inference
# only claims what a path can actually prove, and most ambiguity (a .txt that could be
# data or notes) is left unclaimed rather than guessed at. Add a rule only when the
# pattern reliably names one medium.
#
# Blank lines and lines beginning with '#' are ignored; a trailing '# comment' is stripped.
